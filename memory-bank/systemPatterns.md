# System Patterns

## Quy trình chuẩn
1. Nhận brief/chủ đề.
2. Soạn nội dung bản nháp theo mục tiêu kênh.
3. Sếp duyệt/chỉnh.
4. Chốt bản đăng + hình ảnh + thời gian.
5. Đăng thủ công hoặc hẹn cron.
6. Báo kết quả + link bài.

## Pattern nội dung Facebook
- Mở bằng câu hỏi/nỗi đau người dùng.
- Giải thích ngắn gọn, dễ hiểu.
- 3-5 ý chính kỹ thuật.
- Kết bằng CTA rõ ràng.
- Gắn thông tin liên hệ đầy đủ (khi sếp yêu cầu/chốt dùng).

## Pattern nội dung Website
- Bám checklist SEO/Yoast: focus keyphrase, SEO title, meta description, slug, internal link.
- Tránh trùng lặp nội dung.
- Alt ảnh rõ nghĩa, đúng ngữ cảnh.

## Pattern tự động hóa
- Tác vụ định kỳ/hẹn giờ dùng cron.
- Trước post Facebook: preflight profile đúng (facebook_fujith).
- Ưu tiên lệnh wrapper an toàn khi đăng lịch.
