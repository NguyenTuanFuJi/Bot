# Content Generation

Generate content with a simple workflow:

1. Identify the goal
- Awareness
- Engagement
- Lead generation
- Sales
- Education

2. Identify the output format
- Blog article
- Website page
- Facebook post
- LinkedIn post
- Ad copy
- Email
- Report
- Product description

3. Match the writing style to the audience
- Professional
- Conversational
- Persuasive
- Technical
- Educational
- Premium / high-end

4. Draft in this order
- Hook or opening
- Main value / benefits
- Supporting detail
- CTA or conclusion

5. Improve before delivery
- Remove repetition
- Tighten long sentences
- Keep tone consistent
- Make benefits concrete
- Add formatting that fits the target platform

## Default output patterns

### Website / blog
- Clear title
- Short introduction
- H2/H3 structure
- Internal links if relevant
- Strong conclusion or CTA

### Social post
- Strong first line
- Short paragraphs
- 3-5 useful points max unless long-form is requested
- One main CTA
- Hashtags only when useful

### Sales / marketing copy
- Lead with outcome, not features alone
- Make value concrete
- Reduce fluff
- End with a direct CTA

## Rewrite modes
Use this skill when the user asks to:
- write from scratch
- rewrite for a stronger tone
- shorten or expand content
- make copy more premium
- turn technical text into sales content
- turn long content into social content
- optimize wording before publishing

## Quality bar
Before finalizing, check:
- Is the opening strong enough?
- Is the reader and goal clear?
- Is the structure easy to scan?
- Is the CTA aligned with the goal?
- Is the tone consistent with the brand or request?

If the user provides source material, preserve factual details unless they ask for a larger rewrite.
