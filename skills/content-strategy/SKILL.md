# Content Strategy

Use this skill to turn scattered content ideas into a repeatable system.

## Core workflow

1. Define the business goal
Choose the primary objective:
- awareness
- trust
- leads
- sales enablement
- retention

2. Define the audience
Clarify:
- who the content is for
- what problem they care about
- what objections or questions they have
- which channels they already use

3. Build content pillars
Create 3-5 pillar topics tied to the audience and offer.
Every content idea should fit one pillar.

4. Choose formats and channels
Prioritize 1-2 main channels and 1-2 main formats.
Prefer focus over breadth.

5. Create the calendar
Plan by:
- date
- pillar
- topic
- format
- channel
- CTA
- status

6. Plan distribution
For each strong piece, decide:
- where it is published first
- where it is reposted or adapted
- how it is repurposed
- what CTA it drives

7. Measure and adjust
Track the metric that matches the goal:
- awareness -> reach / impressions / visits
- trust -> engagement / time on page / replies
- leads -> signups / inboxes / CTA clicks
- sales -> assisted conversions / booked calls / purchases

## Recommended outputs
When using this skill, produce one or more of the following:
- content pillars
- topic bank
- weekly or monthly content calendar
- channel / format recommendation
- repurposing workflow
- KPI dashboard suggestion

## Rules of thumb
- Tie content to business goals, not random posting
- Pick one main CTA per content piece
- Build around repeat questions from real customers
- Double down on formats that already perform
- Repurpose winners instead of starting from zero each time

## Use this skill together with content-generation
After the strategy is clear, use `content-generation` to draft the actual posts, articles, or campaigns.
